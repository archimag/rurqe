# Enums через `CHECK (col IN (…))`

В SQLite нет `CREATE TYPE … AS ENUM`, поэтому схема закрывает набор значений
колонки табличным ограничением. Интроспекция CLI восстанавливает такие
колонки в секцию `[[enum]]` файла `schema.lock` — ту же форму, которую
PostgreSQL-диалект получает из `pg_enum`.

```sql
CREATE TABLE tasks (
    id      INTEGER PRIMARY KEY,
    status  TEXT NOT NULL,
    CHECK (status IN ('todo', 'done'))
);
```

## Как это читается

`crates/rurqe-cli/src/introspect/sqlite/check_enums.rs` разбирает DDL
токенным сканером, а не регуляркой: `CHECK`, встреченный внутри строкового
литерала или комментария, не может быть принят за ограничение. Разбор
допускает лишние скобки вокруг колонки и вокруг всего предиката
(`CHECK (((status)) IN (…))`), завершающую запятую в списке значений и
соседние ограничения того же оператора.

Восстановленная пара «колонка → варианты» переносится в каталог как
`TypeKind::Enum`, а собранные перечисления сортируются по имени. Если две
колонки объявляют один и тот же набор вариантов, они делят одно имя
перечисления (имя колонки); если наборы различаются, имя уточняется до
`{table}_{column}_enum` — так разные наборы значений не сливаются в один тип.

## Точные байтовые диапазоны

Сканер сохраняет точный байтовый диапазон подвыражения (в частности, списка
вариантов), поэтому снимок остаётся бит-стабильным между запусками и версиями
SQLite. Именно это требование — и отсутствие у нормализующего парсера
внутренних диапазонов — ратифицирует рукописный лексер как исключение в
`Conventions.md`; гейтом слияния для модуля служит property-набор в
`lexer/property_tests.rs`.

## Что получает кодогенерация

Для перечисленной колонки генерируется типизированный Rust-перечисление,
которое участвует в выражениях как обычное значение — `tasks.status.eq(Status::Done)`
— а список вариантов сверяется с локом, а не с ручной таблицей строк.

Перечисления входят в контрольную сумму лока наравне с остальными объектами
каталога, поэтому drift-верификация поймает переименованный или
переупорядоченный набор вариантов до продакшена.
